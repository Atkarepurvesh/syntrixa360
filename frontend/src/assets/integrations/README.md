# Integration logos

Drop a logo here named after the integration id and it is picked up automatically
(no code change): `<id>.svg | .png | .webp | .jpg`.

Logos added: indiamart, tradeindia, exportersindia, global-sources, made-in-china, udaan (icon only),
justdial, outlook, 99acres, housing-com, magicbricks, pabbly-connect (icon only), microsoft-365.

Use only logos you are allowed to show. Brand names and logos belong to their owners.
